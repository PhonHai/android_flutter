# 2026-07-29 工作日志

## Flutter 调原生 Android 设备能力（NAS 客户端场景）
新增 MethodChannel `com.pomodoro/device`，实现三组 Flutter→原生能力，对标绿联云 NAS App。

### 新增/改动文件
- `native-android/app/src/main/java/com/pomodoro/app/DeviceChannelHandler.kt`（新）：object 单例，register(engine, Activity)/unregister()。三组方法：
  - 权限：requestPermissions（ActivityResultContracts.RequestMultiplePermissions）、isPermissionGranted、openAppSettings
  - 存储：pickDirectory（OpenDocumentTree，SAF 免权限）、getStorageStats（StatFs）
  - WiFi：isWifiEnabled、getWifiInfo（ssid/bssid/ip/rssi/linkSpeed）、openWifiSettings（API29+ 用 Settings.Panel.ACTION_WIFI，旧版降级 ACTION_WIFI_SETTINGS）、startWifiScan（BroadcastReceiver + 5s 超时兜底）
  - 蓝牙：isBluetoothEnabled、requestEnableBluetooth（ACTION_REQUEST_ENABLE via StartActivityForResult）、getPairedDevices、startDiscovery
  - 关键设计：MethodChannel 请求-响应 vs ActivityResult 异步结果，用 pendingXxx 暂存 Result 回填
- `native-android/app/src/main/AndroidManifest.xml`：加权限 ACCESS_WIFI_STATE/CHANGE_WIFI_STATE/ACCESS_FINE_LOCATION、BLUETOOTH(+ADMIN,maxSdk30)、BLUETOOTH_SCAN/CONNECT、NEARBY_WIFI_DEVICES(neverForLocation)、硬件特性声明
- `native-android/app/src/main/java/com/pomodoro/app/FlutterContainerActivity.kt`：onCreate 取缓存引擎注册 device 通道（需 Activity），onDestroy 注销防泄漏
- `flutter_module/lib/channels/device_channel.dart`（新）：DeviceChannel 封装所有方法 + 权限常量
- `flutter_module/lib/navigations/device/device_demo_page.dart`（新）：按钮+日志区演示页
- `flutter_module/lib/app.dart`：注册 `/device_demo` 路由 + 首页加入口按钮

### 处理的 Android 版本现实
- Android 10+ setWifiEnabled 失效 → 跳设置面板
- WiFi 扫描结果/SSID 需 ACCESS_FINE_LOCATION（8.1+）/ NEARBY_WIFI_DEVICES（13+）
- 蓝牙扫描：11- 需位置，12+ 需 BLUETOOTH_SCAN；连接需 BLUETOOTH_CONNECT
- BroadcastReceiver 注册 13+ 需显式 RECEIVER_NOT_EXPORTED

## 增补：原生设置页（Tab 2）加可点击按钮 + 抽共享能力层
用户要求在「设置页面」放可点击按钮触发权限/存储/WiFi/蓝牙。原生 App 底部 4 Tab 的 Tab 2「设置」原是空占位。

### 改动
- 新增 `DeviceCapabilities.kt`：把纯逻辑（isPermissionGranted/openAppSettings/getStorageStats/isWifiEnabled/getWifiInfo/openWifiSettings/startWifiScan/isBluetoothEnabled/getPairedDevices/startDiscovery）抽成共享 object，原生 Compose 与 Flutter MethodChannel 共用一份，避免重复（DRY/面试点）。
- `DeviceChannelHandler.kt` 改为只做 ActivityResult 桥接（权限/SAF/蓝牙开启），其余转发到 DeviceCapabilities；体积大幅缩减。
- 新增 `ui/main/SettingsScreen.kt`：Compose 设置页，按①权限②存储③WiFi④蓝牙分组，按钮可点击；需弹系统框的用 `rememberLauncherForActivityResult`（RequestMultiplePermissions/OpenDocumentTree/StartActivityForResult），其余直接调 DeviceCapabilities；底部调用日志区。
- `MainTabScreen.kt`：Tab 2 由 PlaceholderContent 改为 SettingsScreen。

### 构建验证
- `:app:compileDebugKotlin` 通过（零警告）
- `:app:assembleDebug` BUILD SUCCESSFUL

### 架构亮点
原生设置页与 Flutter 模块共用 DeviceCapabilities 同一份能力实现，消费方两套 ActivityResult 机制（Compose rememberLauncher vs Activity 注册 launcher）。
